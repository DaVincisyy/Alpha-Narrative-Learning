## 🌱 为什么需要数据筛选？

### 真实场景

在 quant-NPL 项目中，我们有成千上万条新闻数据：

```python
# 新闻数据示例
   日期        股票代码  标题              情绪分数  阅读量
0  2024-01-01  000001  公司业绩大涨        0.85    10000
1  2024-01-01  000002  市场波动加剧       -0.32     5000
2  2024-01-02  000001  新产品发布成功      0.76    15000
3  2024-01-02  000003  监管政策收紧       -0.65     8000
4  2024-01-03  000001  股价创新高          0.92    20000
```

我们需要回答这些问题：
- 哪些新闻的情绪分数大于 0.8？
- 000001 股票有哪些新闻？
- 2024-01-02 当天有哪些负面新闻？
- 阅读量超过 10000 的正面新闻有哪些？

**这就是数据筛选的作用！**

## 🔍 布尔索引（Boolean Indexing）

### 什么是布尔索引？

布尔索引是 Pandas 最强大的功能之一。它的原理很简单：

1. 创建一个条件（返回 True/False）
2. 用这个条件筛选数据

### 基础示例

```python
import pandas as pd

df = pd.DataFrame({
    '股票代码': ['000001', '000002', '000003'],
    '价格': [10.5, 20.3, 15.8],
    '涨跌幅': [0.05, -0.02, 0.03]
})

# 步骤1：创建条件（布尔 Series）
condition = df['涨跌幅'] > 0
print(condition)
# 0     True
# 1    False
# 2     True

# 步骤2：用条件筛选
result = df[condition]
print(result)
#    股票代码    价格  涨跌幅
# 0  000001  10.5  0.05
# 2  000003  15.8  0.03
```

### 简写形式（常用）

```python
# 直接在方括号中写条件
result = df[df['涨跌幅'] > 0]
```

## 💻 常用筛选条件

### 1. 数值比较

```python
# 大于
df[df['价格'] > 15]

# 小于
df[df['涨跌幅'] < 0]

# 等于
df[df['价格'] == 10.5]

# 不等于
df[df['股票代码'] != '000001']

# 大于等于
df[df['价格'] >= 15]

# 小于等于
df[df['涨跌幅'] <= 0]
```

### 2. 字符串匹配

```python
# 完全匹配
df[df['股票代码'] == '000001']

# 包含某个字符串
df[df['标题'].str.contains('业绩')]

# 以某个字符串开头
df[df['股票代码'].str.startswith('0000')]

# 以某个字符串结尾
df[df['标题'].str.endswith('成功')]
```

### 3. 多个条件组合

```python
# AND 条件（同时满足）- 使用 &
result = df[(df['价格'] > 10) & (df['涨跌幅'] > 0)]

# OR 条件（满足任一）- 使用 |
result = df[(df['价格'] > 20) | (df['涨跌幅'] > 0.05)]

# NOT 条件（取反）- 使用 ~
result = df[~(df['涨跌幅'] < 0)]  # 等价于 df['涨跌幅'] >= 0

# 复杂组合
result = df[
    (df['价格'] > 10) & 
    (df['涨跌幅'] > 0) & 
    (df['股票代码'] != '000003')
]
```

**⚠️ 注意：**
- 必须用 `&`（AND）、`|`（OR）、`~`（NOT）
- 不能用 `and`、`or`、`not`
- 每个条件必须用括号括起来

### 4. 范围筛选

```python
# 在某个范围内
df[(df['价格'] >= 10) & (df['价格'] <= 20)]

# 使用 between（更简洁）
df[df['价格'].between(10, 20)]

# 在列表中
df[df['股票代码'].isin(['000001', '000002'])]

# 不在列表中
df[~df['股票代码'].isin(['000003'])]
```

## 🎯 查询方法

### 方法1：布尔索引（推荐）

```python
# 最常用的方法
result = df[df['价格'] > 15]
```

### 方法2：query() 方法

```python
# 使用字符串表达式
result = df.query('价格 > 15')

# 多个条件
result = df.query('价格 > 15 and 涨跌幅 > 0')

# 使用变量
threshold = 15
result = df.query('价格 > @threshold')
```

### 方法3：loc 配合条件

```python
# 选择特定行和列
result = df.loc[df['价格'] > 15, ['股票代码', '价格']]
```

## 🎯 在 quant-NPL 项目中的应用

### 场景1：筛选正面新闻

```python
# 情绪分数 > 0.7 的新闻
positive_news = news_df[news_df['sentiment'] > 0.7]
```

### 场景2：筛选特定股票的新闻

```python
# 000001 股票的所有新闻
stock_news = news_df[news_df['stock_code'] == '000001']
```

### 场景3：筛选特定日期的负面新闻

```python
# 2024-01-02 的负面新闻
negative_news = news_df[
    (news_df['date'] == '2024-01-02') & 
    (news_df['sentiment'] < 0)
]
```

### 场景4：筛选高关注度的正面新闻

```python
# 阅读量 > 10000 且情绪分数 > 0.5
hot_positive = news_df[
    (news_df['views'] > 10000) & 
    (news_df['sentiment'] > 0.5)
]
```

## ⚠️ 常见陷阱

### 陷阱1：忘记括号

```python
# ❌ 错误：会报错
df[df['价格'] > 10 & df['涨跌幅'] > 0]

# ✅ 正确：每个条件加括号
df[(df['价格'] > 10) & (df['涨跌幅'] > 0)]
```

### 陷阱2：使用 and/or 而不是 &/|

```python
# ❌ 错误：会报错
df[(df['价格'] > 10) and (df['涨跌幅'] > 0)]

# ✅ 正确：使用 &
df[(df['价格'] > 10) & (df['涨跌幅'] > 0)]
```

### 陷阱3：字符串比较大小写

```python
# 大小写敏感
df[df['标题'] == '公司业绩大涨']  # 必须完全匹配

# 忽略大小写
df[df['标题'].str.lower() == '公司业绩大涨'.lower()]
```

### 陷阱4：空值处理

```python
# 包含空值的列筛选可能出问题
df[df['价格'] > 10]  # 空值会被自动排除

# 显式处理空值
df[df['价格'].notna() & (df['价格'] > 10)]
```
