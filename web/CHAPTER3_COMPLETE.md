## 💡 第 3 章特色

### 1. 函数式编程思想

**传统方式 vs 函数式**
```python
# 传统方式
result = []
for price in prices:
    if price > 100:
        result.append(price * 2)

# 函数式（一行）
result = list(map(lambda x: x * 2, filter(lambda x: x > 100, prices)))
```

### 2. 代码复用

**不用函数（重复代码）**
```python
profit1 = (150 - 100) / 100 * 100
profit2 = (200 - 150) / 150 * 100
profit3 = (180 - 200) / 200 * 100
```

**用函数（简洁清晰）**
```python
def calculate_profit(buy, sell):
    return (sell - buy) / buy * 100

profit1 = calculate_profit(100, 150)
profit2 = calculate_profit(150, 200)
profit3 = calculate_profit(200, 180)
```

### 3. 高阶函数

```python
# 函数作为参数
def apply_operation(data, operation):
    return [operation(x) for x in data]

# 传递不同的函数
doubled = apply_operation(prices, lambda x: x * 2)
squared = apply_operation(prices, lambda x: x ** 2)
```
