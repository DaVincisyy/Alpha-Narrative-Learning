# 🚀 网页版启动指南

## 如何运行

### 方法 1：直接打开（推荐）

1. 进入 web 目录：
```bash
cd "C:\syy\claude project\help-learning\web"
```

2. 双击 `index.html` 文件，会在浏览器中打开

### 方法 2：使用本地服务器（如果方法1不行）

```bash
cd "C:\syy\claude project\help-learning\web"

# 如果你有 Python
python -m http.server 8000

# 然后在浏览器打开
# http://localhost:8000
```

## 📚 使用说明

### 1. 界面介绍

- **顶部**：章节标题和进度条
- **左侧边栏**：练习列表（点击切换）
- **右侧主区域**：课程内容和代码编辑器

### 2. 学习流程

1. **阅读课程介绍**（第一页）
2. **点击左侧"练习 1"**开始第一个练习
3. **在代码编辑器中写代码**
4. **点击"运行测试"**按钮
5. **查看测试结果**：
   - ✅ 绿色 = 通过
   - ❌ 红色 = 失败（会告诉你哪里错了）
6. **完成后点击"下一题"**

### 3. 功能说明

- **运行测试**：检查你的代码是否正确
- **重置代码**：恢复到初始状态
- **进度条**：显示完成了多少练习
- **✅ 标记**：完成的练习会显示绿色对勾

### 4. 练习列表

- 课程介绍
- 练习 1：创建列表
- 练习 2：创建字典
- 练习 3：获取元素
- 练习 4：更新字典
- 练习 5：创建元组
- 练习 6：添加元素
- 练习 7：获取值
- 练习 8：计算长度

## 💡 提示

1. **仔细阅读提示**：每个练习都有详细的提示
2. **看示例代码**：有些练习提供了示例
3. **注意错误信息**：测试失败时会告诉你问题在哪
4. **不要着急**：慢慢来，理解每个概念

## 🎯 完成标准

- 所有 8 个练习都显示 ✅
- 进度条达到 100%

## 📞 遇到问题？

- 检查代码语法（括号、引号、缩进）
- 重新阅读提示和示例
- 使用"重置代码"按钮重新开始

祝你学习愉快！🎓
