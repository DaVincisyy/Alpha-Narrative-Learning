## 🎯 新的教学风格

### Before（小白风格）
```
列表就像购物清单，可以存储多个项目
```

### After（专业风格）
```
列表是动态数组，存储对象引用（PyObject*）
内存布局：连续的指针数组
时间复杂度：索引 O(1)，append 平摊 O(1)
扩容策略：new_size = (n + (n >> 3) + 6) & ~3
```

## 📊 对比示例

### 数据结构讲解

**旧版本：**
> 字典就像通讯录，每个名字对应一个电话号码

**新版本：**
> 字典基于哈希表实现，使用开放寻址法解决冲突
> 平均 O(1) 查找，键必须是可哈希对象
> Python 3.7+ 通过额外索引数组保持插入顺序

### 练习说明

**旧版本：**
> 用方括号 [] 创建列表，元素之间用逗号分隔

**新版本：**
> 列表存储 PyObject* 指针，而非对象本身
> 动态扩容：当 len > allocated 时触发 realloc
> 引用语义：变量存储的是对象引用
