🎯 本章目标

学习 Python 的控制流机制：迭代和条件分支，理解其字节码实现和性能特性。

📚 控制流的本质

程序执行流程的控制：

  • 顺序执行：指令按顺序执行（默认）
  • 条件分支：根据布尔值选择执行路径
  • 循环迭代：重复执行代码块

📊 本章内容

1️⃣ for 循环 - 迭代器协议

底层机制：基于迭代器协议（__iter__ 和 __next__）

# for 循环的本质
for item in iterable:
    process(item)

# 等价于
iterator = iter(iterable)  # 调用 __iter__()
while True:
    try:
        item = next(iterator)  # 调用 __next__()
        process(item)
    except StopIteration:
        break

# 字节码分析
import dis
dis.dis('for x in [1,2,3]: pass')
# GET_ITER
# FOR_ITER
# STORE_NAME
# JUMP_ABSOLUTE

2️⃣ while 循环 - 条件循环

执行机制：每次迭代前检查条件

# while 循环
count = 0
while count < 3:
    print(count)
    count += 1

# 字节码
# LOAD_NAME (count)
# LOAD_CONST (3)
# COMPARE_OP (<)
# POP_JUMP_IF_FALSE
# ... 循环体 ...
# JUMP_ABSOLUTE  # 跳回条件检查

3️⃣ if 条件判断 - 分支跳转

实现方式：基于条件的字节码跳转

# 条件判断
if price > 100:
    category = "high"
else:
    category = "low"

# 字节码
# LOAD_NAME (price)
# LOAD_CONST (100)
# COMPARE_OP (>)
# POP_JUMP_IF_FALSE (else_block)
# ... if 块 ...
# JUMP_FORWARD (end)
# ... else 块 ...
# end:

练习 6：列表推导式 🚀

用一行代码完成练习 5 的功能！

🚀 扩展知识：列表推导式

列表推导式是 Python 的强大特性，可以用一行代码完成循环 + 筛选。

格式：[表达式 for 变量 in 列表 if 条件]

📝 对比：传统方式 vs 列表推导式

# 传统方式（5 行）
squares = []
for num in [1, 2, 3, 4, 5]:
    if num % 2 == 0:
        squares.append(num ** 2)

# 列表推导式（1 行）
squares = [num ** 2 for num in [1, 2, 3, 4, 5] if num % 2 == 0]

print(squares)  # [4, 16]

练习 7：enumerate 函数 🚀

使用 enumerate 同时获取索引和值，返回格式化的字符串列表。

例如：["0: AAPL", "1: GOOGL", "2: MSFT"]

🚀 扩展知识：enumerate

enumerate() 函数可以同时获取索引和值，避免手动维护计数器。

格式：for index, value in enumerate(list):

📝 enumerate 示例

fruits = ["苹果", "香蕉", "橙子"]

# 不用 enumerate（需要手动计数）
for i in range(len(fruits)):
    print(f"{i}: {fruits[i]}")

# 用 enumerate（更简洁）
for i, fruit in enumerate(fruits):
    print(f"{i}: {fruit}")

# 输出：
# 0: 苹果
# 1: 香蕉
# 2: 橙子

练习 8：zip 函数 🚀

使用 zip 同时遍历股票代码和价格，返回字典。

例如：{"AAPL": 150.25, "GOOGL": 2800.50}

🚀 扩展知识：zip

zip() 函数可以将多个列表"打包"在一起，同时遍历。

格式：for a, b in zip(list1, list2):

📝 zip 示例

names = ["Alice", "Bob", "Charlie"]
ages = [25, 30, 35]

# 同时遍历两个列表
for name, age in zip(names, ages):
    print(f"{name} is {age} years old")

# 输出：
# Alice is 25 years old
# Bob is 30 years old
# Charlie is 35 years old

# 创建字典
person_dict = dict(zip(names, ages))
print(person_dict)  # {'Alice': 25, 'Bob': 30, 'Charlie': 35}

练习 9：嵌套循环 🚀

使用嵌套循环生成所有可能的配对。

例如：list1 = ["A", "B"], list2 = [1, 2]

结果：[("A", 1), ("A", 2), ("B", 1), ("B", 2)]

🚀 扩展知识：嵌套循环

嵌套循环就是循环里面还有循环，用于处理多维数据或生成组合。

注意：嵌套循环的时间复杂度是 O(n×m)，数据量大时要小心！

📝 嵌套循环示例

colors = ["红", "蓝"]
sizes = ["S", "M", "L"]

# 生成所有颜色和尺寸的组合
for color in colors:
    for size in sizes:
        print(f"{color}-{size}")

# 输出：
# 红-S
# 红-M
# 红-L
# 蓝-S
# 蓝-M
# 蓝-L
