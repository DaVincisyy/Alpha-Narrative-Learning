🎯 本章目标

学习 Python 中最基础的三种数据容器，理解它们的区别和使用场景。

📚 Python 的内置数据结构

Python 提供了三种核心的序列/映射类型，用于存储和组织数据：

  • 列表（list）：动态数组，存储对象引用
  • 字典（dict）：哈希表实现的键值映射
  • 元组（tuple）：不可变序列，内存效率更高

📊 三种数据结构详解

1️⃣ 列表（List）- 动态数组

底层实现：连续内存块存储对象指针（PyObject*）

特性：可变、有序、支持索引和切片

# 列表存储的是对象引用，而非对象本身
stock_codes = ["AAPL", "GOOGL", "MSFT"]

# 内存模型：[ptr1, ptr2, ptr3] -> [str对象1, str对象2, str对象3]

# 索引访问 - O(1) 时间复杂度
first_stock = stock_codes[0]  # 直接通过指针偏移

# append 操作 - 平摊 O(1)
stock_codes.append("NVDA")  # 动态扩容机制

# 列表是可变对象
stock_codes[0] = "TSLA"  # 原地修改

2️⃣ 字典（Dictionary）- 哈希表

底层实现：基于哈希表，使用开放寻址法解决冲突

特性：键必须可哈希（不可变），平均 O(1) 查找

# 字典的键值映射
company_info = {
    "name": "Apple Inc.",
    "ticker": "AAPL",
    "price": 150.25
}

# 查找过程：hash(key) -> 索引 -> 值
company_name = company_info["name"]  # O(1) 平均时间

# Python 3.7+ 保持插入顺序（通过额外的索引数组）

# 键必须是可哈希对象（不可变）
# 可以：str, int, tuple
# 不可以：list, dict, set

3️⃣ 元组（Tuple）- 不可变序列

底层实现：固定大小的数组，创建后不可修改

特性：不可变、可哈希（可作为字典键）、内存占用更小

# 元组是不可变对象
company_founded = ("Apple", 1976, "California")

# 访问元素 - O(1)
company_name = company_founded[0]

# 不可变性的优势：
# 1. 可以作为字典的键
# 2. 线程安全
# 3. 内存效率更高（无需预留扩容空间）

# ❌ 不能修改
# company_founded[1] = 1977  # TypeError

# 元组解包（unpacking）
name, year, location = company_founded

💡 关键概念

可变 vs 不可变：

  • 可变对象（list, dict, set）：可以原地修改，id 不变
  • 不可变对象（tuple, str, int）：修改会创建新对象

引用语义：Python 中变量存储的是对象引用，而非对象本身

练习 1：创建列表对象

创建一个包含 5 个字符串对象引用的列表。

🔍 深入理解：列表的内存模型

CPython 实现：

typedef struct {
    PyObject_VAR_HEAD
    PyObject **ob_item;  // 指向对象指针数组
    Py_ssize_t allocated;  // 已分配的槽位数
} PyListObject;

关键点：

  • 列表存储的是 PyObject* 指针，而非对象本身
  • 动态扩容：当 len > allocated 时触发 realloc
  • 扩容策略：new_allocated = (n + (n >> 3) + 6) & ~3

💡 实现提示

使用列表字面量语法：[obj1, obj2, ...]

返回包含 5 个字符串引用的列表对象

📝 引用语义示例

# 列表存储引用
a = [1, 2, 3]
b = a  # b 和 a 指向同一个列表对象

b.append(4)
print(a)  # [1, 2, 3, 4] - a 也改变了！

# 验证：id() 返回对象的内存地址
print(id(a) == id(b))  # True

# 浅拷贝 vs 深拷贝
c = a.copy()  # 浅拷贝：创建新列表，但元素仍是引用
print(id(a) == id(c))  # False

练习 2：创建字典对象

创建一个哈希表映射，包含公司的元数据。

🔍 深入理解：字典的哈希表实现

CPython 实现：

typedef struct {
    PyObject_HEAD
    Py_ssize_t ma_used;  // 已使用的键值对数量
    PyDictKeysObject *ma_keys;  // 键数组
    PyObject **ma_values;  // 值数组（或 NULL）
} PyDictObject;

哈希冲突解决：

  • 使用开放寻址法（open addressing）
  • 探测序列：perturb 算法避免聚集
  • 负载因子 > 2/3 时触发 resize

Python 3.7+ 的顺序保持：

  • 使用额外的索引数组记录插入顺序
  • 内存开销增加，但保持了插入顺序

💡 实现提示

使用字典字面量：{"key": value, ...}

键必须是可哈希对象（实现了 __hash__ 和 __eq__）

📝 可哈希性示例

# 可哈希对象（不可变）
hash("string")  # ✓
hash(42)        # ✓
hash((1, 2))    # ✓

# 不可哈希对象（可变）
# hash([1, 2])    # ✗ TypeError
# hash({"a": 1})  # ✗ TypeError

# 自定义类的哈希
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __hash__(self):
        return hash((self.x, self.y))

    def __eq__(self, other):
        return self.x == other.x and self.y == other.y
