📖 第 5 章：面向对象编程

🎯 本章目标

掌握 Python 面向对象编程的核心概念：类、对象、继承、封装和多态。

📚 什么是面向对象

面向对象编程（OOP）是一种编程范式，将数据和操作数据的方法封装在一起：

# 定义一个股票类
class Stock:
    def __init__(self, code, name, price):
        self.code = code
        self.name = name
        self.price = price

    def get_info(self):
        return f"{self.code}: {self.name} - ${self.price}"

# 创建对象
apple = Stock("AAPL", "Apple Inc.", 150.25)
print(apple.get_info())  # AAPL: Apple Inc. - $150.25

📊 本章内容

1️⃣ 类和对象

类是对象的模板，对象是类的实例

class Stock:
    # 类属性（所有实例共享）
    market = "US"

    # 构造函数
    def __init__(self, code, price):
        # 实例属性（每个实例独有）
        self.code = code
        self.price = price

# 创建对象
stock1 = Stock("AAPL", 150)
stock2 = Stock("GOOGL", 2800)

print(stock1.market)  # US（类属性）
print(stock1.code)    # AAPL（实例属性）

2️⃣ 继承

子类继承父类的属性和方法，可以扩展或重写

class Stock:
    def __init__(self, code, price):
        self.code = code
        self.price = price

class TradableStock(Stock):
    def __init__(self, code, price, shares):
        super().__init__(code, price)  # 调用父类构造函数
        self.shares = shares

    def get_value(self):
        return self.price * self.shares

stock = TradableStock("AAPL", 150, 100)
print(stock.get_value())  # 15000

🔍 深入理解：魔法方法

特殊方法让对象支持内置操作：

class Stock:
    def __init__(self, code, price):
        self.code = code
        self.price = price

    def __str__(self):
        # print() 时调用
        return f"{self.code}: ${self.price}"

    def __eq__(self, other):
        # == 比较时调用
        return self.code == other.code

    def __lt__(self, other):
        # < 比较时调用
        return self.price < other.price

stock1 = Stock("AAPL", 150)
stock2 = Stock("GOOGL", 2800)

print(stock1)           # AAPL: $150
print(stock1 == stock2) # False
print(stock1 < stock2)  # True

💡 OOP 的优势

  • 封装：将数据和方法组织在一起
  • 继承：代码复用，扩展功能
  • 多态：不同对象响应相同接口
  • 可维护性：代码结构清晰，易于修改

练习 4：继承

创建 TradableStock 类继承 Stock，添加交易功能。

🔍 深入理解：继承

继承的优势：

  • 代码复用 - 避免重复代码
  • 扩展功能 - 在父类基础上添加新功能
  • 多态性 - 子类对象可以当作父类使用
  • 维护性 - 修改父类影响所有子类

super() 的作用：

  • 调用父类的方法
  • 支持多重继承的 MRO（方法解析顺序）
  • 比直接调用父类名更灵活

💡 实现提示

1. 使用 super().__init__(code, price) 调用父类构造函数

2. 添加 self.shares 属性

3. buy 方法增加 shares：self.shares += amount

📝 继承示例

class Stock:
    def __init__(self, code, price):
        self.code = code
        self.price = price

class TradableStock(Stock):
    def __init__(self, code, price, shares):
        super().__init__(code, price)  # 调用父类
        self.shares = shares

    def buy(self, amount):
        self.shares += amount

    def get_value(self):
        return self.price * self.shares

stock = TradableStock("AAPL", 150, 10)
stock.buy(5)  # 买入5股
print(stock.shares)  # 15
print(stock.get_value())  # 2250

# 设计原则：
# 继承表示 "is-a" 关系
# TradableStock 是一种 Stock
# 优先使用组合而非继承（更灵活）

练习 5：属性装饰器

使用 @property 装饰器创建可控制的属性。

🔍 深入理解：@property

@property 的优势：

  • 像访问属性一样调用方法
  • 可以添加验证逻辑
  • 保持接口一致性
  • 延迟计算（只在访问时计算）

使用场景：

  • 需要验证的属性（如价格必须 > 0）
  • 计算属性（如根据其他属性计算）
  • 只读属性（只定义 getter，不定义 setter）
  • 需要在访问时触发副作用

💡 实现提示

1. getter 返回 self._price

2. setter 验证 value > 0，否则抛出 ValueError

3. 私有属性用下划线开头：_price

📝 @property 示例

class Stock:
    def __init__(self, code, price):
        self.code = code
        self._price = price  # 私有属性

    @property
    def price(self):
        """获取价格"""
        return self._price

    @price.setter
    def price(self, value):
        """设置价格，必须 > 0"""
        if value <= 0:
            raise ValueError("价格必须大于0")
        self._price = value

    @property
    def price_str(self):
        """只读属性：格式化价格"""
        return f"${self._price:.2f}"

stock = Stock("AAPL", 150)
print(stock.price)  # 150 (调用 getter)
stock.price = 160   # 调用 setter
print(stock.price_str)  # $160.00 (只读)

# stock.price = -10  # ValueError!

练习 6：类方法和静态方法

实现类方法和静态方法，理解三种方法的区别。

🔍 深入理解：三种方法

实例方法：

  • 第一个参数是 self（实例本身）
  • 可以访问实例属性和类属性
  • 最常用的方法类型

类方法（@classmethod）：

  • 第一个参数是 cls（类本身）
  • 可以访问类属性，不能访问实例属性
  • 常用于工厂方法（创建实例）

静态方法（@staticmethod）：

  • 没有特殊的第一个参数
  • 不能访问实例属性和类属性
  • 相当于普通函数，只是放在类里

💡 实现提示

1. 类方法返回 cls.total_stocks

2. 静态方法检查代码长度和是否全大写

3. 使用 code.isupper() 和 len(code)

📝 三种方法对比

class Stock:
    total_stocks = 0  # 类属性

    def __init__(self, code):
        self.code = code
        Stock.total_stocks += 1

    # 实例方法
    def get_code(self):
        return self.code

    # 类方法
    @classmethod
    def get_total(cls):
        return cls.total_stocks

    # 静态方法
    @staticmethod
    def is_valid_code(code):
        return len(code) <= 5 and code.isupper()

# 调用方式
stock = Stock("AAPL")
print(stock.get_code())  # 实例方法
print(Stock.get_total())  # 类方法
print(Stock.is_valid_code("AAPL"))  # 静态方法

练习 7：综合应用 - 投资组合类

创建完整的 Portfolio 类，综合运用所学的 OOP 知识。

🔍 深入理解：容器魔法方法

容器协议：

  • __len__ - 返回容器大小
  • __contains__ - 支持 in 运算符
  • __getitem__ - 支持 [] 索引
  • __iter__ - 支持 for 循环

💡 实现提示

1. add_stock 将股票添加到 self.stocks 字典

2. get_total_value 遍历所有股票求和

3. __len__ 返回 len(self.stocks)

4. __contains__ 检查 code in self.stocks

📝 完整示例

class Portfolio:
    def __init__(self, name):
        self.name = name
        self.stocks = {}

    def add_stock(self, stock):
        self.stocks[stock.code] = stock

    def get_total_value(self):
        return sum(s.get_value() for s in self.stocks.values())

    def __len__(self):
        return len(self.stocks)

    def __contains__(self, code):
        return code in self.stocks

    def __str__(self):
        return f"Portfolio({self.name}, {len(self)} stocks)"

# 使用
portfolio = Portfolio("我的投资组合")
portfolio.add_stock(Stock("AAPL", 150))
portfolio.add_stock(Stock("GOOGL", 2800))

print(len(portfolio))  # 2
print("AAPL" in portfolio)  # True
print(portfolio)  # Portfolio(我的投资组合, 2 stocks)
