1️⃣ PyFunctionObject 结构

CPython 中函数对象的内存表示

typedef struct {
    PyObject_HEAD
    PyObject *func_code;        // 代码对象（字节码）
    PyObject *func_globals;     // 全局命名空间
    PyObject *func_defaults;    // 默认参数值
    PyObject *func_kwdefaults;  // 关键字默认参数

    PyObject *func_name;        // 函数名
    PyObject *func_dict;        // __dict__ 属性
    PyObject *func_annotations; // 类型注解
} PyFunctionObject;

# 访问函数属性
def example(x, y=10):

print(example.__code__)      # code object
print(example.__defaults__)  # (10,)
print(example.__name__)      # 'example'

2️⃣ 参数传递机制

位置参数、默认参数、关键字参数的字节码实现

def func(a, b=10, *args, **kwargs):
    pass

# 字节码分析
import dis
dis.dis(func)

# 调用约定
func(1)              # LOAD_CONST, CALL_FUNCTION 1
func(1, 2)           # LOAD_CONST, LOAD_CONST, CALL_FUNCTION 2
func(1, b=2)         # LOAD_CONST, LOAD_CONST, CALL_FUNCTION_KW
func(1, 2, 3, 4)     # CALL_FUNCTION_EX (with *args)
func(1, x=2, y=3)    # CALL_FUNCTION_EX (with **kwargs)

# 参数解析时间复杂度
# 位置参数：O(1) - 直接索引
# 关键字参数：O(k) - k 为关键字数量
# *args/**kwargs：O(n) - 构建元组/字典

🔍 深入理解：LEGB 作用域规则

名称查找顺序：

# L - Local（局部）
# E - Enclosing（闭包）
# G - Global（全局）
# B - Built-in（内置）

x = "global"

def outer():
    x = "enclosing"

    def inner():
        x = "local"
        print(x)  # local

    inner()

outer()

# 字节码指令
# LOAD_FAST    - 局部变量（最快）
# LOAD_DEREF   - 闭包变量（cell 对象）
# LOAD_GLOBAL  - 全局变量（字典查找）
# LOAD_NAME    - 动态查找（最慢）

🚀 高阶函数与惰性求值

函数作为参数和返回值，迭代器的惰性特性

# map/filter 返回迭代器（惰性）
numbers = [1, 2, 3, 4, 5]
squared = map(lambda x: x**2, numbers)
print(type(squared))  # 

# 不立即计算，按需生成
for value in squared:
    print(value)  # 1, 4, 9, 16, 25

# 对比列表推导式（立即求值）
squared_list = [x**2 for x in numbers]  # 立即分配内存

# 性能对比
# map/filter：O(1) 空间，惰性求值
# 列表推导式：O(n) 空间，立即求值
# 选择依据：是否需要多次遍历

练习 3：写入 CSV 文件

将股票数据写入 CSV 文件，使用 csv.DictWriter 处理字典列表。

🔍 深入理解：CSV 格式

CSV（Comma-Separated Values）：

  • 纯文本格式，每行一条记录
  • 字段用逗号分隔（可自定义分隔符）
  • 第一行通常是表头（字段名）
  • Excel 和数据库都支持导入导出

csv 模块优势：

  • 自动处理特殊字符（逗号、引号、换行）
  • DictWriter 让代码更清晰
  • 支持自定义方言（dialect）

💡 实现提示

1. 使用 csv.DictWriter(file, fieldnames)

2. 调用 writer.writeheader() 写入表头

3. 使用 writer.writerows(stocks) 写入所有行

📝 CSV vs JSON 对比

# CSV 格式（表格数据）
code,name,price
AAPL,Apple,150.25
GOOGL,Google,2800.50

# JSON 格式（嵌套数据）
[
  {"code": "AAPL", "name": "Apple", "price": 150.25},
  {"code": "GOOGL", "name": "Google", "price": 2800.50}
]

# 选择依据：
# CSV：Excel 兼容、文件更小、适合表格数据
# JSON：支持嵌套、Web API 常用、可读性好

📝 JSON 方法对比

import json

# dump() - 写入文件
with open('data.json', 'w') as f:
    json.dump(data, f, indent=4)

# dumps() - 转为字符串
json_str = json.dumps(data, indent=4)

# load() - 从文件读取
with open('data.json', 'r') as f:
    data = json.load(f)

# loads() - 从字符串解析
data = json.loads(json_str)

练习 6：异常处理基础

安全地转换价格字符串为浮点数，处理可能的转换错误。

🔍 深入理解：异常处理机制

try-except 工作原理：

  • try 块：可能出错的代码
  • except 块：捕获并处理异常
  • else 块：没有异常时执行
  • finally 块：无论如何都执行（清理资源）

常见异常类型：

  • ValueError - 值类型正确但值不合法
  • TypeError - 类型错误
  • FileNotFoundError - 文件不存在
  • KeyError - 字典键不存在
  • ZeroDivisionError - 除以零
  • IndexError - 索引越界

💡 实现提示

1. 使用 try-except ValueError

2. try 块中尝试 float(price_str)

3. except 块中返回 0.0

📝 异常处理最佳实践

# ✅ 好的做法：捕获具体异常
try:
    price = float(price_str)
except ValueError:
    price = 0.0

# ❌ 不好的做法：捕获所有异常
try:
    price = float(price_str)
except:  # 会隐藏其他错误
    price = 0.0

# 完整的异常处理
try:
    price = float(price_str)
except ValueError as e:
    print(f"转换失败: {e}")
    price = 0.0
else:
    print("转换成功")
finally:
    print("清理资源")

练习 7：文件异常处理

安全地读取文件，处理文件不存在的情况。

🔍 深入理解：文件操作异常

常见文件异常：

  • FileNotFoundError - 文件或目录不存在
  • PermissionError - 没有权限访问文件
  • IsADirectoryError - 期望文件但是目录
  • IOError - 输入输出错误

💡 实现提示

1. 使用 try-except FileNotFoundError

2. try 块中读取文件内容

3. except 块中返回 None

📝 文件操作最佳实践

# with 语句自动处理异常
try:
    with open(filename, 'r') as f:
        content = f.read()
    return content
except FileNotFoundError:
    print(f"文件不存在: {filename}")
    return None
except PermissionError:
    print(f"没有权限: {filename}")
    return None

# with 语句保证文件关闭
# 即使发生异常也会正确关闭

练习 8：综合应用 - 数据验证

加载 CSV 文件并验证数据，跳过无效行。

🔍 深入理解：多层异常处理

嵌套异常处理：

  • 外层捕获文件异常（FileNotFoundError）
  • 内层捕获数据异常（ValueError）
  • 每层处理不同类型的错误
  • 保证程序健壮性

💡 实现提示

1. 外层 try-except 处理文件不存在

2. 内层 try-except 处理数据转换错误

3. 跳过无效行，继续处理下一行

📝 数据验证示例

import csv

def load_and_validate_stocks(filename):
    try:
        with open(filename, 'r') as f:
            reader = csv.DictReader(f)
            valid_stocks = []

            for row in reader:
                try:
                    # 验证数据
                    price = float(row['price'])
                    if price > 0:
                        valid_stocks.append(row)
                except (ValueError, KeyError):
                    # 跳过无效行
                    continue

            return valid_stocks
    except FileNotFoundError:
        return []
