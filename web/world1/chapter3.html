📖 第 3 章：函数对象与高阶函数

🎯 本章目标

理解 Python 函数作为一等公民的本质，掌握函数对象、闭包、高阶函数的底层机制。

📚 函数是对象

Python 中函数是 PyFunctionObject 实例，可以赋值、传递、作为返回值：

# 函数对象的特性
def calculate_profit(buy_price, sell_price):
    return (sell_price - buy_price) / buy_price * 100

# 函数是对象
print(type(calculate_profit))  # 
print(id(calculate_profit))    # 内存地址

# 可以赋值给变量
calc = calculate_profit
result = calc(100, 150)  # 50.0

# 可以存储在容器中
operations = [calculate_profit, abs, round]

📊 本章内容

1️⃣ PyFunctionObject 结构

CPython 中函数对象的内存表示

typedef struct {
    PyObject_HEAD
    PyObject *func_code;        // 代码对象（字节码）
    PyObject *func_globals;     // 全局命名空间
    PyObject *func_defaults;    // 默认参数值
    PyObject *func_kwdefaults;  // 关键字默认参数
    PyObject *func_closure;     // 闭包（cell 对象）
    PyObject *func_doc;         // 文档字符串
    PyObject *func_name;        // 函数名
    PyObject *func_dict;        // __dict__ 属性
    PyObject *func_annotations; // 类型注解
} PyFunctionObject;

# 访问函数属性
def example(x, y=10):
    return x + y

print(example.__code__)      # code object
print(example.__defaults__)  # (10,)
print(example.__name__)      # 'example'

2️⃣ 参数传递机制

位置参数、默认参数、关键字参数的字节码实现

def func(a, b=10, *args, **kwargs):
    pass

# 字节码分析
import dis
dis.dis(func)

# 调用约定
func(1)              # LOAD_CONST, CALL_FUNCTION 1
func(1, 2)           # LOAD_CONST, LOAD_CONST, CALL_FUNCTION 2
func(1, b=2)         # LOAD_CONST, LOAD_CONST, CALL_FUNCTION_KW
func(1, 2, 3, 4)     # CALL_FUNCTION_EX (with *args)
func(1, x=2, y=3)    # CALL_FUNCTION_EX (with **kwargs)

# 参数解析时间复杂度
# 位置参数：O(1) - 直接索引
# 关键字参数：O(k) - k 为关键字数量
# *args/**kwargs：O(n) - 构建元组/字典

🔍 深入理解：LEGB 作用域规则

名称查找顺序：

# L - Local（局部）
# E - Enclosing（闭包）
# G - Global（全局）
# B - Built-in（内置）

x = "global"

def outer():
    x = "enclosing"

    def inner():
        x = "local"
        print(x)  # local

    inner()

outer()

# 字节码指令
# LOAD_FAST    - 局部变量（最快）
# LOAD_DEREF   - 闭包变量（cell 对象）
# LOAD_GLOBAL  - 全局变量（字典查找）
# LOAD_NAME    - 动态查找（最慢）

🚀 高阶函数与惰性求值

函数作为参数和返回值，迭代器的惰性特性

# map/filter 返回迭代器（惰性）
numbers = [1, 2, 3, 4, 5]
squared = map(lambda x: x**2, numbers)
print(type(squared))  # 

# 不立即计算，按需生成
for value in squared:
    print(value)  # 1, 4, 9, 16, 25

# 对比列表推导式（立即求值）
squared_list = [x**2 for x in numbers]  # 立即分配内存

# 性能对比
# map/filter：O(1) 空间，惰性求值
# 列表推导式：O(n) 空间，立即求值
# 选择依据：是否需要多次遍历

练习 3：多返回值

定义函数返回列表的最小值和最大值。

🔍 深入理解：元组打包与解包

元组打包（Tuple Packing）：

  • return a, b 实际返回一个元组 (a, b)
  • Python 自动将多个值打包成元组
  • 括号可以省略：return (a, b) 等价于 return a, b

元组解包（Tuple Unpacking）：

  • min_val, max_val = get_min_max(prices)
  • 解包时数量必须匹配，否则报错
  • 可以用 * 收集剩余元素：a, *rest, b = (1,2,3,4,5)

💡 实现提示

1. 使用内置函数 min(prices) 和 max(prices)

2. 返回两个值：return min(prices), max(prices)

3. 接收时可以解包：min_val, max_val = get_min_max(prices)

📝 多返回值示例

def get_min_max(prices):
    return min(prices), max(prices)

# 解包接收
min_price, max_price = get_min_max([100, 150, 120])
print(min_price)  # 100
print(max_price)  # 150

# 不解包，接收元组
result = get_min_max([100, 150, 120])
print(result)  # (100, 150)
print(type(result))  # 

# 实际应用：返回多个相关值
def analyze_stock(prices):
    return min(prices), max(prices), sum(prices)/len(prices)

min_p, max_p, avg_p = analyze_stock([100, 150, 120])

练习 4：默认参数

定义带默认值的函数，计算商品总价。

🔍 深入理解：默认参数

默认参数规则：

  • 默认参数在函数定义时设置
  • 调用时可以省略有默认值的参数
  • 默认参数必须在必需参数之后
  • 默认值在函数定义时计算（只执行一次）

⚠️ 可变默认参数陷阱：

  • 不要使用可变对象（列表、字典）作为默认值
  • 默认值只创建一次，多次调用会共享同一对象
  • 正确做法：使用 None，函数内判断并创建新对象

💡 实现提示

1. 定义参数：def calculate_total(price, quantity=1, tax=0.1)

2. 计算公式：price * quantity * (1 + tax)

3. 返回计算结果

📝 默认参数示例

def calculate_total(price, quantity=1, tax=0.1):
    return price * quantity * (1 + tax)

# 使用默认值
print(calculate_total(100))  # 110.0

# 指定部分参数
print(calculate_total(100, 2))  # 220.0

# 指定所有参数
print(calculate_total(100, 2, 0.15))  # 230.0

# 使用关键字参数
print(calculate_total(100, tax=0.2))  # 120.0

# ❌ 错误示例：可变默认参数
def add_item(item, items=[]):
    items.append(item)
    return items

print(add_item(1))  # [1]
print(add_item(2))  # [1, 2] - 共享同一列表！

# ✅ 正确做法
def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items

练习 6：lambda 函数

创建 lambda 函数计算平方。

🔍 深入理解：lambda 表达式

lambda 特点：

  • 创建匿名函数（没有名字的函数）
  • 语法：lambda 参数: 表达式
  • 只能包含单个表达式，不能有语句
  • 表达式的值自动返回

lambda vs def：

  • lambda 适合简单的一次性函数
  • def 适合复杂逻辑和需要复用的函数
  • 性能完全相同，只是语法不同

💡 实现提示

1. 语法：square = lambda x: x ** 2

2. 或者：square = lambda x: x * x

📝 lambda 示例

# lambda 函数
square = lambda x: x ** 2
print(square(5))  # 25

# 等价的 def 函数
def square(x):
    return x ** 2

# 使用场景：作为参数传递
stocks = [
    {"code": "AAPL", "price": 150},
    {"code": "GOOGL", "price": 2800},
    {"code": "MSFT", "price": 300}
]

# 按价格排序
stocks.sort(key=lambda s: s["price"])

# 过滤高价股票
expensive = list(filter(lambda s: s["price"] > 200, stocks))

# map 转换
prices = list(map(lambda s: s["price"], stocks))

练习 7：map 函数

使用 map 对列表中每个元素应用函数。

🔍 深入理解：map 函数

map 工作原理：

  • map(函数, 可迭代对象) 对每个元素应用函数
  • 返回迭代器（惰性求值，节省内存）
  • 需要用 list() 转换成列表
  • 不修改原列表，返回新结果

map vs 列表推导式：

  • map 返回迭代器，节省内存
  • 列表推导式立即创建列表
  • 列表推导式可读性更好
  • map 适合链式操作

💡 实现提示

1. 使用 map(lambda x: x * 2, prices)

2. 用 list() 转换结果

3. 返回列表

📝 map 示例

prices = [100, 150, 200]

# 使用 map
doubled = list(map(lambda x: x * 2, prices))
print(doubled)  # [200, 300, 400]

# 等价的列表推导式
doubled = [x * 2 for x in prices]

# 转换数据类型
str_prices = ['100', '200', '300']
prices = list(map(float, str_prices))

# 批量处理
names = ['apple', 'google', 'microsoft']
uppercase = list(map(str.upper, names))
print(uppercase)  # ['APPLE', 'GOOGLE', 'MICROSOFT']

练习 8：filter 函数

使用 filter 筛选列表元素。

🔍 深入理解：filter 函数

filter 工作原理：

  • filter(函数, 可迭代对象) 筛选满足条件的元素
  • 函数返回 True 的元素被保留
  • 返回迭代器（惰性求值）
  • 需要用 list() 转换成列表

filter vs 列表推导式：

  • 列表推导式更 Pythonic，可读性更好
  • filter 适合已有判断函数的情况
  • 列表推导式可以同时转换和筛选

💡 实现提示

1. 使用 filter(lambda x: x > threshold, prices)

2. 用 list() 转换结果

3. 返回列表

📝 filter 示例

prices = [50, 100, 150, 200, 250]

# 使用 filter
high_prices = list(filter(lambda x: x > 100, prices))
print(high_prices)  # [150, 200, 250]

# 等价的列表推导式
high_prices = [x for x in prices if x > 100]

# 筛选有效数据
valid_prices = list(filter(lambda x: x > 0, prices))

# 组合 map 和 filter
result = list(map(
    lambda x: x * 2,
    filter(lambda x: x > 100, prices)
))
print(result)  # [300, 400, 500]

练习 9：函数作为参数

高阶函数：接收函数作为参数。

🔍 深入理解：高阶函数

高阶函数定义：

  • 接收函数作为参数的函数
  • 或者返回函数的函数
  • Python 中函数是一等公民

高阶函数优势：

  • 代码更灵活，可以传入不同的操作
  • 减少重复代码
  • 函数式编程的基础

💡 实现提示

1. 遍历 prices 列表

2. 对每个元素调用 operation 函数

3. 返回结果列表

📝 高阶函数示例

def apply_operation(prices, operation):
    return [operation(price) for price in prices]

# 传入不同的函数
prices = [100, 150, 200]

# 翻倍
doubled = apply_operation(prices, lambda x: x * 2)
print(doubled)  # [200, 300, 400]

# 打折
discounted = apply_operation(prices, lambda x: x * 0.8)
print(discounted)  # [80.0, 120.0, 160.0]

# 格式化
formatted = apply_operation(prices, lambda x: f"${x}")
print(formatted)  # ['$100', '$150', '$200']

# 高阶函数的实际应用
def create_multiplier(factor):
    """返回一个乘法函数"""
    return lambda x: x * factor

double = create_multiplier(2)
triple = create_multiplier(3)

print(double(10))  # 20
print(triple(10))  # 30

练习 10：综合应用 - 股票数据处理

综合运用函数、lambda、map、filter 处理股票数据。

🔍 深入理解：函数式编程

函数式编程特点：

  • 函数是一等公民，可以传递和返回
  • 避免副作用，不修改外部状态
  • 使用纯函数，相同输入总是相同输出
  • 链式操作，代码更简洁

Python 函数式工具：

  • map、filter、reduce
  • lambda 表达式
  • 列表推导式
  • 生成器表达式

💡 实现提示

1. 使用 filter 筛选价格 > 100 的股票

2. 使用 map 提取股票代码

3. 转换为列表并返回

📝 综合应用示例

stocks = [
    {"code": "AAPL", "price": 150},
    {"code": "GOOGL", "price": 2800},
    {"code": "MSFT", "price": 300},
    {"code": "TSLA", "price": 80}
]

def get_expensive_stock_codes(stocks, threshold):
    # 筛选高价股票
    expensive = filter(lambda s: s["price"] > threshold, stocks)
    # 提取代码
    codes = map(lambda s: s["code"], expensive)
    # 转换为列表
    return list(codes)

result = get_expensive_stock_codes(stocks, 100)
print(result)  # ['AAPL', 'GOOGL', 'MSFT']

# 链式操作
result = list(map(
    lambda s: s["code"],
    filter(lambda s: s["price"] > 100, stocks)
))

# 等价的列表推导式（更 Pythonic）
result = [s["code"] for s in stocks if s["price"] > 100]
