## 🔥 第 2 章的特色

### 对比教学
```python
# 传统方式（5 行）
result = []
for price in prices:
    if price > 100:
        result.append(price)

# 列表推导式（1 行）
result = [price for price in prices if price > 100]
```

### 实用技巧
- enumerate：避免手动计数
- zip：同时遍历多个列表
- 列表推导式：更 Pythonic
