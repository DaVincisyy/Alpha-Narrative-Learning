## 🎯 作业目标

- ✅ 函数定义

---

## 📋 任务描述

你需要实现一个股票投资组合管理器，包含以下功能：

### 功能 1：添加股票
向投资组合添加新股票（包括代码、价格、持有数量）

### 功能 2：计算总价值
计算整个投资组合的总价值

### 功能 3：查找最贵的股票
找出价格最高的股票

### 功能 4：筛选高价值持仓
找出价值（价格 × 数量）超过指定金额的股票

### 功能 5：生成投资报告
生成包含统计信息的报告字典

## 💡 提示

1. **添加股票**：创建字典，添加到列表
2. **计算总价值**：循环累加 `price * shares`
3. **查找最贵**：循环比较，记录最大值
4. **筛选**：循环 + if 判断
5. **报告**：创建字典，填入统计数据
