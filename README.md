# 🎓 从零开始学习量化 NLP 项目

> 一个互动式、游戏化的 Python 数据分析学习平台

## 🌟 欢迎！

这是一个专为**完全零基础**的学习者设计的教学项目。通过学习这个课程，你将：

- ✅ 掌握 Python 编程基础
- ✅ 学会使用 Pandas 处理数据
- ✅ 理解自然语言处理（NLP）
- ✅ 学习量化金融分析
- ✅ 能够独立运行和改进 quant-NPL 项目

- **第 4 章**：文件与异常处理 - 11 个练习

**共 52 个练习**

- **第 4 章**：DataFrame 入门
- **第 5 章**：数据筛选与查询
- **第 6 章**：数据统计与可视化
- **📝 作业 2**：财报数据分析器

### 🧠 世界 3：NLP 魔法学院（3 章）
理解文本处理和情绪分析。

- **第 7 章**：文本处理基础
- **第 8 章**：情绪分析原理
- **第 9 章**：项目核心代码解读
- **📝 作业 3**：简易情绪分析器

### 📈 世界 4：量化分析城（3 章）

- **第 10 章**：因子工程
- **第 11 章**：数据可视化

### 🚀 世界 5：实战项目岛（2 章）
运行和扩展真实项目。

- **第 13 章**：完整流程实战
- **第 14 章**：进阶挑战
- **📝 最终项目**：你的量化策略

## 🎯 如何使用

### 快速开始

```bash
# 1. 查看所有练习
python test.py --list

# 2. 开始第一个练习
code world1_python_basics/chapter1_data_containers/exercises/exercise_1.py

# 3. 完成代码后测试
python test.py 1.1.1
```

### 目录结构

每个章节包含：
- `lesson.md` - 知识点讲解（从零开始，非常详细）
- `exercises/` - 练习代码目录（每个练习一个文件）
  - `exercise_1.py` - 练习 1
  - `exercise_2.py` - 练习 2
  - ...
- `tests/` - 自动测试代码（不需要修改）

### 测试命令

```bash
# 测试单个练习
python test.py 1.1.1    # world1, chapter1, 练习1
python test.py 1.2.3    # world1, chapter2, 练习3

# 测试整个章节
python test.py 1.1      # world1, chapter1 所有练习

# 测试整个 world
python test.py 1        # world1 所有章节
```

### World 1 练习总览

- **Chapter 1 - 数据容器** (8 个练习)
- **Chapter 2 - 循环与条件** (8 个练习)
- **Chapter 3 - 函数** (15 个练习)
- **Chapter 4 - 文件与异常** (11 个练习)
- **Chapter 5 - 面向对象** (10 个练习)

## 📖 学习建议

1. **按顺序学习**：每章都建立在前面的基础上
2. **动手实践**：不要只看，一定要自己写代码
3. **运行测试**：通过所有测试才算真正掌握
4. **完成作业**：作业帮助你融会贯通
5. **不要着急**：每章 30-60 分钟，慢慢来

## ⏱️ 预估时间

- **世界 1-2**：6 章 + 2 作业 ≈ 5-7 小时
- **世界 3-4**：6 章 + 2 作业 ≈ 5-7 小时
- **世界 5**：2 章 + 最终项目 ≈ 3-5 小时
- **总计**：约 15-20 小时

## 🆘 遇到问题？

- 每个章节的 `lesson.md` 都有详细解释
- 测试失败时会显示具体错误信息
- 可以查看 `solutions/` 目录中的参考答案（建议先自己尝试）
